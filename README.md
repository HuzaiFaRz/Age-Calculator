# 🎂 Age Calculator

An age calculator web application that calculates a user's age based on the selected date of birth.

🔗 Live Demo: https://huzaifaagecalculator.netlify.app/  
🔗 GitHub Repo: https://github.com/HuzaiFaRz/Age-Calculator  

---

## 📌 Project Overview

This project calculates the exact age of a user by comparing the selected birth date with the current date using JavaScript date functions.

---

## ✨ Features

- Date input field
- Accurate age calculation
- Instant result display
- Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Date Object)

---

## 🎯 Learning Outcomes

- Working with JavaScript Date object
- Logic building for real-time calculations
- Input handling and validation
- Dynamic result rendering
